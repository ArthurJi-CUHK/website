# Arthur Ji · AI for Health

Bilingual academic homepage for Arthur (Xiang) Ji / 纪祥.

Live site: https://ArthurJi-CUHK.github.io/ArthurJi/

Built with static HTML, CSS and JavaScript. No installation or build step required.

- `index.html`: page structure and English copy
- `content.js`: publications, honours, timeline and Chinese copy
- `styles.css`: responsive visual design
- `app.js`: language switch, research interaction, piano and optional analytics
- `config.js`: optional visitor-statistics endpoint (disabled by default)

Run locally with `python3 -m http.server 8765` from this directory.
GitHub Pages: deploy the `main` branch, repository root.

No background music, tracking pixels or third-party fonts. The optional piano uses
locally synthesized notes only after user interaction. The photo contains no EXIF metadata.
Visitor analytics is currently disabled. No invented visits are displayed.

Research prototypes are not medical diagnostic tools. Linked lab projects are
attributed to the lab and distinguished from personal publications. The anonymous
DemScreen manuscript and private application documents are not included.

Publication titles and author order are retained in English in both language modes.
Copyright in the profile text and photograph remains with their respective owners.
